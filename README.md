# Glow Button ✨

A pure CSS glow button with a rotating gradient glow. No JavaScript, no libraries.

## Features

- Pure HTML + CSS
- Rotating blue, green and orange glow
- Easy to customize (colors, blur, speed, size)
- Works in any project

## Customize

| Variable | What it does | Default |
|---|---|---|
| `--c1`, `--c2`, `--c3` | Glow colors | blue, green, orange |
| `--blur` | Glow softness | `14px` |
| `--dur` | Rotation speed | `3s` |
| `--scale` | Glow size | `1.1` |

## Browser support

Chrome/Edge 85+, Safari 16.4+, Firefox 128+
